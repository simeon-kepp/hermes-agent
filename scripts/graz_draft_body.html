One-Liner:
curl -fsSL https://raw.githubusercontent.com/simeon-kepp/hermes-agent/main/scripts/install-graz.sh | bash

Was das Skript macht:

  • Erkennt automatisch das Betriebssystem (Linux, macOS, WSL, Termux)
  • Clont den Fork simeon-kepp/hermes-agent mit allen Skills und Einstellungen
  • Portiert alle individuellen Skills aus ~/.hermes/skills (1:1)
  • Initialisiert RuVector-Schema und Engram-Schema
  • Schreibt config.yaml mit RFI-IRFOS-Defaults
  • Installiert Hermes komplett inklusive Dependencies
  • Linkt das hermes Command nach ~/.local/bin/
  • Keine Secrets nötig — API-Keys macht der User danach mit hermes model
